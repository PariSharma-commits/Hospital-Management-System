# Hospital Management System

A full-stack Hospital Management System developed to manage hospital operations such as doctor records, patient records, and appointment scheduling through a centralized platform.

## Features

* Doctor management
* Patient management
* Appointment scheduling
* Department management
* Database integration
* REST API-based backend
* Role-based system architecture

## Project Structure

```text
Hospital-Management-System
├── backend
├── frontend
└── database
```

### Backend

Contains the server-side application, API routes, business logic, and database interaction code.

### Frontend

Contains the user interface built with React and Vite.

### Database

Contains SQL scripts for database schema creation and sample data population.

## Tech Stack

### Frontend

* React
* Vite
* JavaScript
* CSS

### Backend

* Python

### Database

* SQL
* Relational Database System

## Database Files

* `schema.sql` — Database schema definition
* `seed.sql` — Sample data insertion script

## Getting Started

### Frontend

```bash
cd frontend
npm install
npm run dev
```

### Backend

```bash
cd backend
pip install -r requirements.txt
python run.py
```

### Database

Execute the SQL scripts in your database environment:

1. Run `schema.sql`
2. Run `seed.sql`
